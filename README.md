# Neo-Sim · 新模拟城市

[English](README_EN.md) | **中文**

## **_一切皆模拟_**

基于 **NeoForge 1.21.1** 开发的模拟城市类模组，致敬并延续 [Sim-U-Kraft](https://www.mcmod.cn/class/489.html)，并接入 [投影](https://www.mcmod.cn/class/2261.html)支持的格式

算法上的改造见 [算法改进](算法改进.md)。

---

## 特色功能

### 自动化建筑
- 保留 **155 项 Sim-U-Kraft 旧版社区建筑**
- 支持 **投影** 文件，导入自定义建筑

### 自动化生产
- **工作盒** 自动作业：农业、矿业、快递、整地
- **模组方块 / 作物自动兼容**：扫描已装模组的注册表，模组作物自动进入农业盒并写进 `NeoSim/Json/compat/crops.json`；依附性方块（火把、梯子、悬挂类等）可在游戏内一键加入依附方块表

### 特色方块

| 方块 | 特色                                                         |
| --- |------------------------------------------------------------|
| **快递盒** `delivery_box` | 建筑工地缺料时，快递员从站点箱子取料、走路送到工地，投料扣款                             |
| **重建模盒** `rebuild_box` | 放在建筑控制箱旁，读取相邻箱子材料，自动把缺失方块补回去；**不需要 建筑师** |

### NPC
- 多样化市民样貌，支持导入自定义皮肤
- 支持自定义市民姓名

### 建筑预览
- 半透明建筑虚影，**移动 / 旋转 / 镜像** 自由调整蓝图，支持自由视角鸟瞰
- **缓存** 渲染，再大的建筑也不掉帧

### 城市与模拟
- 玩家新建 / 加入城市，市民随城市生活
- **HUD 实时显示**，缺料提醒、完工全城公告

### 界面自定义
- **HUD 随你摆**：大小、位置（九宫格锚点，也可在预览框里直接拖动）、文字颜色、阴影、背景板，以及**显示哪几项**（城市 / 时间 / 星期 / 天数 / 人口 / 资金 / 模式 / 开场倒计时）与顺序
- **投影随你调**：染色、透明度、**方块纹理显示度**（0 = 纯色虚影，100% = 完整贴图；默认值与原观感一致）
- 设置**按玩家保存**在 `NeoSim/Json/ui/<玩家名>.json`，存盘即生效；界面页可「重置本页 / 重置全部界面」

### 标记圈地
- 用 **标记棒** 围出矩形地块，放置盒子自动绑定，地块四角快照固定
- 明确的地块范围 **显示** 光幕

### 多人游戏
- **建造区域冲突检测**：同一区域不会重复建造，先到先得
- **安全校验**：各操作按玩家限流，防止高频请求炸服

## 可配置内容

模组的可配置内容分两处，**全部靠文件管理，不需要命令**：

| 位置 | 管什么 | 生效方式 |
| --- | --- | --- |
| `config/neo-sim.toml` | 数值 / 开关 / 公告文案（费用、概率、上限） | 改后重载世界 |
| `NeoSim/Json/<分类>/*.json` | 内容表：依附性方块表、模组作物表（**支持其他模组的方块与作物**） | 存盘即热重载，无需重启 |
| `NeoSim/Json/ui/<玩家名>.json` | **个人外观设置**：HUD 大小 / 位置 / 颜色 / 显示项，投影染色 / 透明度 / 纹理显示度 | 存盘即热重载；界面页里保存或重置也行 |

- 首次运行自动生成 `NeoSim/Json/` 目录与带注释的模板文件，打开就能改
- 游戏内按 **`I`** 打开「城市信息」→「配置」页：查看全部规则、把**手持方块一键加入表**、切换依附方式、停用 / 删除、保存即生效；「界面」页里自定义 HUD 与投影外观（**按玩家保存**，可一键重置）
- 外部文件覆盖内置规则；解析失败只跳过该文件，原因写在 `NeoSim/Json/_state/errors.txt`

完整说明（目录分类、JSON 字段、GUI 布局、加载与热重载规则）见 **[可配置内容](可配置内容.md)**。
