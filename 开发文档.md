# 开发文档（Neo-Sim · 新模拟城市）

---

## 一、开发目的

### 1. 开发高版本的模拟城市，并开源

以 **Minecraft 1.21.1 / NeoForge** 为平台，复刻并延续经典 Mod *Sim-U-Kraft* 的城市模拟玩法（建筑自动建造、NPC 居民、城市资金/人口/天数、生活系统等），最终开源。

### 2. 提供多样化的模组支持

- 接入 **[Litematica 投影]** 格式（`.litematic`）建筑蓝图，并完整兼容 **Sim-U-Kraft 旧版 `.txt` 建筑**（内置 155 个社区旧建筑）。
- 保留旧版数字方块 ID（1.6.4 时代）→ 现代方块状态的映射体系，可通过外部 JSON 覆盖扩展。
- 支持导入自定义 NPC 皮肤（文件系统皮肤目录 + Mojang 皮肤下载）。

## 三、整体架构与包结构

包根：`com.wenzai.neosim`。注册入口 `NeoSim`（Common）+ `NeoSimClient`（仅客户端）。

| 包                   | 职责                                                                                                                                                             |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `（根）`               | 主类 `NeoSim`/`NeoSimClient`、`Config`、`Command`、`ModItems`、`CreativeModeTabs`                                                                                    |
| `block`             | 方块类：`BuildingConstructor`（建筑模盒）、`ControlBox`（控制箱）、`ModBlocks`（注册表，内联 `MARKER`/农业盒/矿业盒/快递盒）                                                                     |
| `schematic`         | 蓝图数据模型、格式解析（`.litematic` / `.txt`）、块调色板/位数组存储、旧 ID 映射、材料计算、坐标变换                                                                                                |
| `schematic.reader`  | `ISchematicReader` 接口 + `LitematicaSchematicReader` + `SimUKraftSchematicReader`                                                                               |
| `schematic.mapping` | `BlockIdMapping` 旧版数字方块 ID → 现代方块状态                                                                                                                            |
| `building`          | 自动建造系统：`ConstructionEngine` 调度、`ConstructionTask` 状态机、`BuildingInstance`、持久化、区块强制加载、箱子物品管理、破坏处理 `BreakHandler`                                                 |
| `npc`               | NPC 实体 `Entity`、生成/人口 `Manage`、AI 目标 `NpcGoals`、生活点 `CityLivingManager`                                                                                        |
| `life`              | 生活系统：每日结算 `LifeSystem`、房租 `RentSystem`                                                                                                                         |
| `client.gui`        | 客户端界面：`Run`（模式选择）、`City`（城市）、`NPC`（NPC 管理）、`BuildingConstructorGui`（建造）、`ControlBoxGui`、`PreviewAdjustGui`、`HUD`                                               |
| `client.render`     | 客户端渲染：`Model`（NPC 模型）、`Renderer`（NPC 渲染器）                                                                                                                      |
| `client`            | 客户端：汉化表 `BuildingNameLocalizer`、数据缓存 `ClientDataHolder`                                                                                                        |
| `client.preview`    | 建造预览：预览管理/状态/输入/渲染/缓存、自由相机                                                                                                                                     |
| `network`           | 网络包分组容器：`ServerToClientPayloads`（内嵌 S→C：SyncData/OpenGui/ResourceShortage/BuildingComplete）、`ClientToServerPayloads`（内嵌 C→S：Update/FreezeNpc/ConfirmPlacement） |
| `util`              | 通用工具：`RateLimiter`（限流）                                                                                                                                         |
| `storage`           | 数据持久化：`FileCreater`、`ModSavedData`、`SimData`（含内嵌 `CityData`）、`NpcData`                                                                                         |
| `datagen`           | 数据生成：入口 `Data` + `BlockStates`、`LootTables`、`Recipes`、`LangZhCn`、`LangEnUs`                                                                                    |

**加载链路**：`NeoSim` 构造 → 注册物品/方块/实体/创造页签 → 注册命令、HUD、网络包 → `onPlayerJoin` 同步数据并弹窗 → `ServerTickEvent` 驱动天数推进与生活系统 → 服务端停止时清空静态状态。

```
    └── data/                                  # 数据根目录
        │
        ├── data.json                          # [服务器] 全局存档数据
        │                                     #   { mode, dayOfWeek, runGuiSent, joinedPlayers[] }
        ├── {cityName}/                        # [服务器] 按城市隔离
        │   ├── data.json                      # 城市数据  { population, day, credit }
        │   ├── player.json                    # 城市玩家列表 { "players": [...] }
        │   ├── npc/                           # NPC 目录
        │   │   └── {npcName}.json             # 单个 NPC 存档
        │   ├── BuildingConstructor.json       # 建造任务持久化（各使用中建筑模盒状态）
        │   └── ControlBox.json                # 控制箱记录（建筑信息/生活点/居民/租金）
        │
        └── {saveName}/                        # [非服务器] 按世界存档名隔离
            ├── data.json                      # 该存档的全局数据
            └── {cityName}/
                ├── data.json
                ├── player.json
                ├── npc/
                │   └── {npcName}.json
                ├── BuildingConstructor.json
                └── ControlBox.json
```

## 六、数据格式（JSON 结构）

### 1. 全局数据 `data.json`（`ModSavedData` / `SimData`）

```json
{
  "mode": 1,                 // 运行模式：0=未选择 1=普通 2=创造 3=困难
  "dayOfWeek": 2,            // 星期（0~6，随天+1 取模 7）
  "runGuiSent": true,        // 首个玩家是否已弹 Run 界面
  "joinedPlayers": ["<UUID>"] // 已触发过首次弹窗的玩家
}
```

> `population/day/credit` 不落在此文件，实际存于城市 `data.json`，`SimData.getData()` 读取时合并。

### 2. 城市数据 `data.json`（`SimData.CityData`）

```json
{
  "population": 3,           // 人口（short，上限 Config.MAX_POPULATION=200）
  "day": 1,                  // 天数（起始 1）
  "credit": 10.0             // 城市资金（保留两位小数）
}
```

### 3. 玩家列表 `player.json`

```json
{ "players": ["player1", "player2"] }
```

### 4. NPC 存档 `npc/{npcName}.json`（`NpcData`，`storage/`）

```json
{
  "name": "张伟",              // 全名（= 姓 + 名）
  "surname": "张",             // 姓
  "givenName": "伟",           // 名
  "sex": "male",               // male / female
  "skin": "skins/male/peaq.png",  // 皮肤路径；file: 前缀 = Skins/ 目录下自定义皮肤
  "uuid": "<UUID字符串>",
  "position": { "x": 0, "y": 64, "z": 0 },   // 位置（读取缺省回退 0/64/0）
  "yaw": 0.0,
  "pitch": 0.0,
  "health": 20.0,
  "maxHealth": 20.0,
  "age": 18,                   // 年龄（随机于 Config.npcMinAge~npcMaxAge）
  "job": { "architect": 1, "farmer": 1, "miner": 1, "courier": 1 },  // 四职业等级
  "home": { "x": 0, "y": 0, "z": 0 },        // [有家时] 生活点坐标
  "homeBuilding": "公寓A"      // [有家时] 所住建筑名
}
```

> 注意：`restToday`（今日休息）与工地坐标 `site` **不写 JSON**，仅存于实体 NBT。

### 5. 建造任务 `BuildingConstructor.json`（`BuildingPersistence`）

| `facing`                                   | 放置时玩家面朝（可空）                                                                                                      |
| `buildProgress`                            | 当前进度索引                                                                                                           |
| `buildingComplete` / `phaseTwo` / `paused` | 完工 / 第二轮 / 暂停标志                                                                                                  |

### 8. 方块 ID 映射 `block_id_mapping.json`（`BlockIdMapping`）

对象，键为 `"<旧数字方块ID>:<meta>"`，值为现代方块状态字符串：

```json
{ "0:0": "minecraft:air", "5:0": "minecraft:oak_planks", "5:1": "minecraft:spruce_planks" }
```

值支持属性语法 `"minecraft:oak_door[half=lower,facing=north]"`。外部 `NeoSim/block_id_mapping.json` 与内置合并，**外部条目优先**。未映射方块回退 `minecraft:structure_void`。

## 七、核心子系统

### 1. 方块与注册（`block` / `ModItems` / `ModBlocks` / `CreativeModeTabs`）

| 方块                               | ID                                            | 用途                                                                      |
| -------------------------------- | --------------------------------------------- | ----------------------------------------------------------------------- |
| 建筑模盒 `BuildingConstructor`       | `building_constructor`                        | 右键打开 `BuildingConstructorGui`（建造管理）                                     |
| 控制箱 `ControlBox`                 | `control_box`                                 | 有记录且无进行中任务时右键打开 `ControlBoxGui`；无战利品表                                   |
| 标记棒 `Marker`（`ModBlocks.MARKER`） | `marker`                                      | 蓝图特殊标记生成的方块；玩家放置登记为矩形顶点（服务端全局 `MarkerManager`），同一高度 4 个构成最大轴对齐矩形时渲染水平光束 |
| 农业盒 / 矿业盒 / 快递盒                  | `farming_box` / `mining_box` / `delivery_box` | 已注册，暂无逻辑（预留）                                                            |

- 全部注册到创造页签 `neosim_tab`（图标为建筑模盒）。
- `BreakHandler` 拦截破坏：拆 **建筑模盒** → 解雇 NPC（`WORKER_MAP` 清理 + 复位抬手动画/手持）+ 取消建造任务 + 删除对应控制箱记录并驱逐居民；拆 **控制箱** → 删记录并驱逐居民。
- **标记棒**（`Marker` + `MarkerManager`）：玩家放置（`setPlacedBy`，建造 `setBlock` 不触发）登记到**全局**列表（无玩家隔离，**无聊天提示**），**保留所有标记**（不淘汰最旧）；每次变更后重算"**同一高度**、**面积最大的轴对齐矩形**"的 4 个标记，仅这 4 个生效（其余无效），由 `MarkerBeamRenderer` 画 4 条**水平光束**围出矩形周界；服务端广播 `MarkerSyncPayload`（维度 + 活动矩形四角），新玩家入城补发；跨维度放置清空重建；破坏只移除被拆的那个；变更时剔除已加载区块中已被拆/炸毁的残留标记。

### 2. 蓝图系统（`schematic`）

- **格式**：`SchematicFormat` 枚举 —— `.litematic`（主）、`.txt`（Sim-U-Kraft 旧版）、`.schem`/`.nbt`（预留）、`UNKNOWN`。
- **注册中心** `SchematicRegistry`（单例）：`initializeAsync()` 启动守护线程**异步加载** —— 内置映射 + 外部覆盖映射 → 遍历 4 种 `BuildingType`（Residential/Commercial/Industrial/Other），`old/` 用 `SimUKraftSchematicReader`、`new/` 用 `LitematicaSchematicReader`，统一归一为 `SchematicData` 并按目录强制归型。提供按类型/作者/尺寸/名称搜索（`w:`/`h:`/`d:` 前缀、`/author`、Levenshtein 建议）。开发环境资源路径缺失时回退 `GAMEDIR/../src/main/resources/`。
- **数据模型** `SchematicData`：蓝图名、作者、尺寸、格式/类型、`LightweightBlockContainer`（方块）、`tileEntities`、`entities`、`specialMarkers`。
- **紧凑存储**：`BlockStatePalette`（方块状态↔ID 双向，线性→哈希两阶段，动态位宽）↔ `LightweightBitArray`（long[] 位打包）↔ `LightweightBlockContainer`（X-major 三维索引，实体方块计数缓存）。
- **旧 ID 映射** `BlockIdMapping`：`convert(id, meta)` → `BlockState`，支持内置+外部覆盖。
- **特殊标记** `SpecialMarker`：`.txt` 字符标记 → `!` 生活点（不落块，作居民生成点）、`$` 控制箱、`*` 萤石灯、`0`~`9` 标记棒。
- **坐标变换** `CoordTransform`：Sim-U-Kraft 朝向映射 + Minecraft 旋转/镜像。
- **材料计算** `MaterialCalculator`：统计蓝图方块需求（按物品、降序）；`isAttachedBlock` 判定依附类方块（门/床/告示牌/火把等，须第二轮放置）；普通模式仅基础建材耗材（木板/羊毛/圆石/玻璃/砖类/泥土/石头/深板岩/凝灰岩/黑石/玄武岩/方解石/花岗岩/闪长岩/安山岩/末地石/砂岩/海晶石/石英/栅栏/原木·菌柄·竹块/铜块，栅栏门免费，装饰功能方块一律免费）；创造模式全免费；困难模式仅水/岩浆/草/床/告示牌/蛋糕/门/台阶/耕地免费。
- ~~**导出** `SchematicDataWriter`~~：零调用，已删除（2026-08-08）；当前不支持写回 `.litematic`。

### 3. 建造系统（`building`）

- **调度** `ConstructionEngine`：每 tick 轮询全部 `ConstructionTask`（`synchronized(tasks)` 保护）；`createBuilding(...)` 是建造入口 —— 构建 `BuildingInstance` → **AABB 相交冲突检测**（与现有任务相交则拒绝）→ 建任务置 `WAITING_FOR_WORKER` → 区块强制加载 → 非创造模式一次性扣费（`实心方块数 × CREDITS_PER_BLOCK`）→ 落盘。服务端停止落盘、重启后等蓝图加载完成一次性恢复（`BuildingPersistence.loadFromCity`），跳过缺蓝图/模盒已拆的任务并重建雇佣关系。
- **状态机** `ConstructionTask`（每 tick 只放 1 个方块）：`WAITING_FOR_WORKER → WORKER_ASSIGNED`（等 NPC 到模盒上方）→ `LOADING_BLUEPRINT`（扫箱子）→ `BUILDING`。两轮建造：先实心方块，再依附类方块（门/床等）；**夜晚下班**（≥12000 时工人回生活点，未到岗的新工明日出发）。材料取自**控制箱/模盒 6 邻面箱子**（`InventoryManager`），不足转 `WAITING_FOR_RESOURCES` 每 3 秒复查并广播缺料包。每放一块 NPC 右手抬起动画（0.8~1.2 随机音高）+ 建造技能成长（`0.001/等级`，写入 NPC 存档）。完工 → `COMPLETE` → 广播完工包 → 注册生活点（建造者优先入住）→ NPC 自动辞职。
- **数据模型** `BuildingInstance`：蓝图引用、控制箱/模盒坐标、rotation/mirror/facing、进度、暂停、雇佣关系、作者/放置者。
- **持久化**：`BuildingPersistence`（`BuildingConstructor.json`）、`ControlBoxPersistence`（`ControlBox.json`，含生活点/居民/租金）。
- **区块加载** `BuildingChunkLoader`：为建筑覆盖区块注册 BORDER region ticket 强制加载，拆除时释放。
- **网络触发**：缺料 `ServerToClientPayloads.ResourceShortagePacket`、完工 `ServerToClientPayloads.BuildingCompletePacket`（均只发给建筑所属城市玩家，放置者未入城则广播全部）。

### 4. NPC 系统（`npc`）

- **实体** `Entity`（`PathfinderMob`，注册 `nsnpc`）：随机姓名（中文百家姓+名，30% 单字/70% 双字）、性别、年龄、皮肤（男女各 10 个内置皮肤 + `file:` 自定义 + Mojang 皮肤下载）。四职业等级（architect/farmer/miner/courier）。
- **AI**：`FloatGoal`、`MoveToSiteGoal`（走向工地）、`GoHomeGoal`（夜晚回家）、`StayHomeGoal`（白天休息）、躲避玩家、随机漫步、注视玩家；卡住 >60 tick 直接传送到目标上方。被分配工地后只保留移动/浮游/注视类 goal。
- **冻结机制**：玩家打开 NPC GUI 时 `ClientToServerPayloads.FreezeNpcPayload(id, true)` → `freezeBy(uuid)` 引用计数冻结（停导航、清 goal、面向玩家）；关 GUI 解冻。`cleanupStaleOpeners` 每 200 tick + 玩家下线时清理，修复**断线/崩溃导致 NPC 永久冻结**。
- **生成/人口** `Manage`：`spawnWithAnnouncement`/`spawnAt`（生成+随机属性+入城+分配住房+存 JSON+公告）；`replenishPopulation` 每游戏分钟检查补人（达人口上限或有流浪者则不补，有存档无实体先 `restoreAll` 恢复）。`getPopulation` 以 npc 目录 `.json` 文件数统计。
- **生活点** `CityLivingManager`：建筑完工注册空位 → 建造者/无家 NPC 入住（`assignHome`，生活点被堵向上找空气）；NPC 死亡退房；建筑被拆驱逐居民。
- **持久化**：JSON（`npcData`，字段见 §六.4）+ 实体 NBT（姓名/性别/城市/皮肤/年龄/职业/工地/家/休息标记）。受伤同步到 JSON、死亡删文件。
- **渲染**：`Model`（人类模型，宽/细臂自动判定：检查皮肤 x=47、y=52~63 列透明像素；抬手动画慢起快落插值）+ `Renderer`（皮肤纹理加载缓存、16 格内常显姓名）。

### 5. 生活系统（`life`）

- `LifeSystem.onDayStart`（每天清晨，`NeoSim` tick 检测跨天触发）：先 `RentSystem.collectRent` 收租，再 `rollRestToday` 为有家无业 NPC 掷 25% 休息骰。
- `LifeSystem.onServerTick`：每游戏分钟（1200 tick）按活跃城市 `Manage.replenishPopulation` 自动补人；`announce` 向城市在线玩家广播。
- `RentSystem.collectRent`：遍历城市全部控制箱记录，跳过无居民/非住宅；租金 `rec.rent()>0 ? rent : LIFE_RENT_DEFAULT`，累加进城市 `credit` 并公告；**创造模式（mode==2）不收租**。

| 包                         | 方向  | 内容                                                         | 用途                                                                        |
| ------------------------- | --- | ---------------------------------------------------------- | ------------------------------------------------------------------------- |
| `SyncDataPayload`         | S→C | mode/population/dayOfWeek/day/credit/cityName              | 全量同步，刷新 `ClientDataHolder`/HUD                                            |
| `UpdatePayload`           | C→S | mode 或 (entityId+姓/名/皮肤)                                   | 改运行模式 / NPC 重命名换肤                                                         |
| `OpenGuiPayload`          | S→C | `RUN`/`CITY`                                               | 通知客户端弹窗（`NeoSimClient` 延迟打开）                                              |
| `FreezeNpcPayload`        | C→S | entityId + frozen                                          | 冻结/解冻 NPC                                                                 |
| `ConfirmPlacementPayload` | C→S | schematicName/origin/rotation/mirror/constructorPos/facing | 联机确认放置；服务端做 **RateLimiter(1s)** + 蓝图名（禁 `..`/`/`/`\`）+ 建筑高度 + 玩家 50 格范围校验 |
| `ResourceShortagePacket`  | S→C | schematicName/itemName/neededCount/constructorPos          | 缺料通知                                                                      |
| `BuildingCompletePacket`  | S→C | schematicName/position                                     | 完工公告                                                                      |
| `MarkerSyncPayload`       | S→C | 维度 key + 活动矩形四角列表                                          | 标记棒活动矩形同步（放置/破坏重算后广播、新玩家入城补发；无聊天提示）                                       |

- 网络包注册于 `NeoSim.registerPayloads`（NeoForge PayloadRegistrar，`neo_sim` 命名空间，version "1.0"）。
- 数据同步白名单：仅发给 `player.json` 中含有的城市玩家。
- 8 种 payload 由原 7 个独立文件合并为 2 个容器类：S→C 归 `ServerToClientPayloads`，C→S 归 `ClientToServerPayloads`；引用形式为 `ServerToClientPayloads.SyncDataPayload` / `ClientToServerPayloads.ConfirmPlacementPayload` 等。

### 9. 数据持久化（`storage`）

- `FileCreater`：目录创建、`player.json` 读写（去重追加）、城市查找/列表、`findPlayerCity` 按玩家归属反查城市。

- `NpcData`（自 `npc/` 移入）：NPC JSON 读写删。
- `ClientDataHolder`（客户端单例，现于 `client/`）：`ServerToClientPayloads.SyncDataPayload` 更新，存档切换时重置。

## 八、核心流程

### 1. 玩家首次进入

`onPlayerJoin` → 查玩家所属城市（`findPlayerCity`，无则弹 Run/City）→ 城市玩家则 `ServerToClientPayloads.SyncDataPayload` → 首个玩家且 `mode==0` 弹 **Run**，其余首次进入玩家弹 **City**。Run 选模式 → `ClientToServerPayloads.UpdatePayload(mode)` → City 创建/选择城市（写 `player.json`、建目录、单机生成首个 NPC）。

### 2. 建筑放置与建造

右键模盒 → `BuildingConstructorGui` 选类型/蓝图 → 需求页（材料+费用）→ `SchematicPreviewManager.enterPreview` 半透明预览 → `PreviewAdjustGui` 调整/碰撞检测 → 确认（单机直调 / 联机 `ClientToServerPayloads.ConfirmPlacementPayload` + 服务端校验）→ `ConstructionEngine.createBuilding`（冲突检测+扣费）→ 雇佣工人（`WORKER_MAP`）→ `ConstructionTask` 状态机逐块建造（两轮：实心→依附）→ 缺料广播 / 完工广播 → 拆除/暂停/恢复。

### 3. NPC 生命周期

城市创建（单机）/自动补人 → `spawnWithAnnouncement` 生成（随机属性 + 分配住房）→ 被雇佣/分配工地 → 白天建造 / 夜晚回家 → 每日收租结算 → 受伤同步/死亡删档退房 → 重启 `restoreAll` 从 JSON 恢复。

### 4. 每日结算

服务端 tick 检测跨天 → `incrementDay`（星期+1、天数+1）→ `LifeSystem.onDayStart` → `RentSystem.collectRent`（收租入城市资金）+ `rollRestToday`（25% 休息骰）→ 每小时刻补人。
